================================================================================
                  RECIPE BOOK AND MEAL PLANNER SYSTEM
               
                     User: System Administrator
           
                      Functional Requirements

+----------+------------------------------+---------------------------------------+
|  No.     |  Feature / Requirement       |  Description                          |
+----------+------------------------------+---------------------------------------+
|  6.0     |  Administrator Home Page     |  All admin features are accessible    |
|          |                              |  from the home page upon login.       |
+----------+------------------------------+---------------------------------------+
|  6.1     |  Login                       |  [ref All User 1.2]                   |
|          |                              |  The administrator logs in using      |
|          |                              |  username and password. A forgot      |
|          |                              |  password option is provided.         |
+----------+------------------------------+---------------------------------------+
|  6.2     |  Admin Dashboard             |  Provides full platform oversight     |
|          |                              |  through account management, recipe   |
|          |                              |  moderation, nutrition database       |
|          |                              |  management, usage reports, and       |
|          |                              |  system announcements.                |
+----------+------------------------------+---------------------------------------+
|  6.2.1   |  Side Menu                   |  Contains all navigation buttons for  |
|          |                              |  System Administrator features.       |
+----------+------------------------------+---------------------------------------+
|  6.2.1.1 |  Dashboard Button            |  Navigates to the main admin          |
|          |  [ref 6.2]                   |  dashboard view.                      |
+----------+------------------------------+---------------------------------------+
|  6.2.1.2 |  View Profile Button         |  [ref All User 1.3.1.2]               |
|          |                              |  Opens the profile page showing name, |
|          |                              |  email, gender, phone number, date of |
|          |                              |  birth, and profile picture.          |
+----------+------------------------------+---------------------------------------+
|  6.2.1.3 |  Edit Profile Button         |  [ref All User 1.3.1.2.7]             |
|          |                              |  Opens the edit form pre-filled with  |
|          |                              |  existing values. On submission,      |
|          |                              |  updated info is saved and the admin  |
|          |                              |  returns to the view profile page.    |
+----------+------------------------------+---------------------------------------+
|  6.2.1.4 |  Change Profile Picture      |  [ref All User 1.3.1.2.8]             |
|          |  Button                      |  Opens an upload control. On          |
|          |                              |  submission, the new picture is saved |
|          |                              |  and the admin returns to view        |
|          |                              |  profile.                             |
+----------+------------------------------+---------------------------------------+
|  6.2.1.5 |  Change Password Button      |  [ref All User 1.3.1.5]               |
|          |                              |  Opens a form to enter current        |
|          |                              |  password, new password, and confirm  |
|          |                              |  new password. On submission, the     |
|          |                              |  password is updated.                 |
+----------+------------------------------+---------------------------------------+
|  6.2.1.6 |  Manage Users Button         |  Opens the user management panel      |
|          |                              |  showing all registered accounts in   |
|          |                              |  a table with name, email, role, and  |
|          |                              |  account status.                      |
+----------+------------------------------+---------------------------------------+
| 6.2.1.6.1|  Show All User Accounts      |  Displays all registered user         |
|          |                              |  accounts in a searchable and         |
|          |                              |  sortable table.                      |
+----------+------------------------------+---------------------------------------+
| 6.2.1.6.2|  Activate Account            |  Displays a confirmation prompt. On   |
|          |                              |  confirmation, sets the selected      |
|          |                              |  account status to active.            |
+----------+------------------------------+---------------------------------------+
| 6.2.1.6.3|  Suspend Account             |  Displays a confirmation prompt. On   |
|          |                              |  confirmation, sets the selected      |
|          |                              |  account status to suspended,         |
|          |                              |  preventing further login.            |
+----------+------------------------------+---------------------------------------+
| 6.2.1.6.4|  Delete Account              |  Displays a confirmation prompt. On   |
|          |                              |  confirmation, permanently removes    |
|          |                              |  the account and all associated       |
|          |                              |  data from the platform.              |
+----------+------------------------------+---------------------------------------+
| 6.2.1.6.5|  Pending Accounts Tab        |  Shows newly registered accounts      |
|          |                              |  awaiting administrator approval      |
|          |                              |  before they receive full platform    |
|          |                              |  access.                              |
+----------+------------------------------+---------------------------------------+
| 6.2.1.6.6|  Approve Account             |  Grants full platform access to the   |
|          |                              |  selected pending account.            |
+----------+------------------------------+---------------------------------------+
| 6.2.1.6.7|  Reject Account              |  Denies access to the selected        |
|          |                              |  pending account and sends a          |
|          |                              |  rejection notification to the        |
|          |                              |  applicant's registered email.        |
+----------+------------------------------+---------------------------------------+
|  6.2.1.7 |  Moderate Recipes Button     |  Opens the recipe moderation panel    |
|          |                              |  showing all shared and public        |
|          |                              |  recipes including flagged items,     |
|          |                              |  with flag status and submission      |
|          |                              |  date.                                |
+----------+------------------------------+---------------------------------------+
| 6.2.1.7.1|  Show All Shared Recipes     |  Displays all shared and public       |
|          |                              |  recipes with flag status and         |
|          |                              |  submission date in a table.          |
+----------+------------------------------+---------------------------------------+
| 6.2.1.7.2|  Review Recipe Detail        |  Opens the full recipe content:       |
|          |                              |  title, full ingredient list,         |
|          |                              |  step-by-step instructions, and       |
|          |                              |  tags.                                |
+----------+------------------------------+---------------------------------------+
| 6.2.1.7.3|  Edit Recipe                 |  Allows the administrator to update   |
|          |                              |  any field of the recipe and save     |
|          |                              |  the changes.                         |
+----------+------------------------------+---------------------------------------+
| 6.2.1.7.4|  Hide Recipe                 |  Removes the recipe from public view  |
|          |                              |  without permanently deleting it.     |
|          |                              |  Returns to the full recipe list      |
|          |                              |  [ref 6.2.1.7.1].                     |
+----------+------------------------------+---------------------------------------+
| 6.2.1.7.5|  Remove Recipe               |  Displays a confirmation prompt. On   |
|          |                              |  confirmation, permanently deletes    |
|          |                              |  the recipe from the platform and     |
|          |                              |  returns to the full recipe list      |
|          |                              |  [ref 6.2.1.7.1].                     |
+----------+------------------------------+---------------------------------------+
|  6.2.1.8 |  Nutrition Database Button   |  Opens the nutritional reference      |
|          |                              |  database panel showing all           |
|          |                              |  ingredient entries in a paginated    |
|          |                              |  table with name, calories, protein,  |
|          |                              |  carbohydrates, and fat per 100 g.    |
+----------+------------------------------+---------------------------------------+
| 6.2.1.8.1|  Show All Nutrition Entries  |  Displays all nutrition reference     |
|          |                              |  entries in a paginated table:        |
|          |                              |  ingredient name, calories, protein,  |
|          |                              |  carbohydrates, fat per 100 g.        |
+----------+------------------------------+---------------------------------------+
| 6.2.1.8.2|  Add New Entry               |  Accepts ingredient name and all      |
|          |                              |  nutritional values per 100 g. On     |
|          |                              |  submission, saves the new entry and  |
|          |                              |  returns to the entry table           |
|          |                              |  [ref 6.2.1.8.1].                     |
+----------+------------------------------+---------------------------------------+
| 6.2.1.8.3|  Edit Entry                  |  Shows existing values and accepts    |
|          |                              |  updated values. On submission,       |
|          |                              |  saves the updated entry and          |
|          |                              |  returns to the entry table           |
|          |                              |  [ref 6.2.1.8.1].                     |
+----------+------------------------------+---------------------------------------+
| 6.2.1.8.4|  Delete Entry                |  Displays a confirmation prompt. On   |
|          |                              |  confirmation, permanently removes    |
|          |                              |  the entry and returns to the entry   |
|          |                              |  table [ref 6.2.1.8.1].               |
+----------+------------------------------+---------------------------------------+
|  6.2.1.9 |  Usage Reports Button        |  Generates an on-demand usage report  |
|          |                              |  showing active user count, total     |
|          |                              |  session count, and per-feature       |
|          |                              |  usage statistics. Supports date      |
|          |                              |  range filtering and export.          |
+----------+------------------------------+---------------------------------------+
| 6.2.1.9.1|  Show Usage Report           |  Displays active user count, total    |
|          |                              |  session count, and per-feature       |
|          |                              |  usage statistics for the selected    |
|          |                              |  date range.                          |
+----------+------------------------------+---------------------------------------+
| 6.2.1.9.2|  Date Range Filter           |  Accepts a start date and end date.   |
|          |                              |  Applies the filter to the report     |
|          |                              |  data and refreshes the report view.  |
+----------+------------------------------+---------------------------------------+
| 6.2.1.9.3|  Export as PDF               |  Generates and downloads the current  |
|          |                              |  report as a PDF file containing      |
|          |                              |  accurate report data.                |
+----------+------------------------------+---------------------------------------+
| 6.2.1.9.4|  Export as Excel             |  Generates and downloads the current  |
|          |                              |  report as an .xlsx file containing   |
|          |                              |  accurate report data.                |
+----------+------------------------------+---------------------------------------+
| 6.2.1.10 |  Announcements Button        |  Opens the announcement composer.     |
|          |                              |  The admin enters a title and body    |
|          |                              |  text, submits, and the message is    |
|          |                              |  broadcast to the notification panel  |
|          |                              |  of every active registered user.     |
+----------+------------------------------+---------------------------------------+
|6.2.1.10.1|  Taking Announcement Title   |  Accepts the subject line of the      |
|          |                              |  announcement as a required text      |
|          |                              |  input.                               |
+----------+------------------------------+---------------------------------------+
|6.2.1.10.2|  Taking Announcement Body    |  Accepts the main body text of the    |
|          |                              |  announcement.                        |
+----------+------------------------------+---------------------------------------+
|6.2.1.10.3|  Submit Announcement         |  Broadcasts the announcement to the   |
|          |                              |  notification panel of every active   |
|          |                              |  registered user account.             |
+----------+------------------------------+---------------------------------------+
|6.2.1.10.4|  Sent Announcements History  |  Displays a table of previously sent  |
|          |                              |  announcements showing title, date    |
|          |                              |  sent, and recipient count.           |
+----------+------------------------------+---------------------------------------+
| 6.2.1.11 |  Logout Button               |  [ref All User 1.3.1.6]               |
|          |                              |  Ends the admin session and           |
|          |                              |  redirects to the login page.         |
+----------+------------------------------+---------------------------------------+
|  6.2.2   |  Header                      |  [ref All User 1.3.2]                 |
|          |                              |  Displays platform logo on top left,  |
|          |                              |  logged-in username on top right,     |
|          |                              |  and logout button on top right.      |
+----------+------------------------------+---------------------------------------+
|  6.2.3   |  Footer                      |  [ref All User 1.3.3]                 |
|          |                              |  Displays links to Privacy Policy,    |
|          |                              |  Disclaimer, and About Us pages.      |
+----------+------------------------------+---------------------------------------+

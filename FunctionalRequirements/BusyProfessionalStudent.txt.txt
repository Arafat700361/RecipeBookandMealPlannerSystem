================================================================================
                   RECIPE BOOK AND MEAL PLANNER SYSTEM
                           
                              User: Student

                        Functional Requirements

+----------+------------------------------+---------------------------------------+
|  No.     |  Feature / Requirement       |  Description                          |
+----------+------------------------------+---------------------------------------+
|  5.0     |  User Home Page              |  All features are accessible from the |
|          |                              |  home page upon login.                |
+----------+------------------------------+---------------------------------------+
|  5.1     |  Registration                |  New users register by providing full |
|          |  [ref All User 1.1]          |  name, email, username, password,     |
|          |                              |  confirm password, gender, phone      |
|          |                              |  number, and date of birth. The form  |
|          |                              |  can be submitted or reset.           |
+----------+------------------------------+---------------------------------------+
|  5.2     |  Login                       |  Registered users log in using        |
|          |  [ref All User 1.2]          |  username and password. A forgot      |
|          |                              |  password option is provided.         |
+----------+------------------------------+---------------------------------------+
|  5.3     |  Dashboard                   |  The main dashboard provides access   |
|          |                              |  to all features through a side menu, |
|          |                              |  header, and footer.                  |
+----------+------------------------------+---------------------------------------+
|  5.3.1   |  Side Menu                   |  Contains all navigation buttons for  |
|          |                              |  Busy Professional / Student features.|
+----------+------------------------------+---------------------------------------+
|  5.3.1.1 |  Dashboard Button            |  Navigates the user back to the main  |
|          |  [ref 5.3]                   |  dashboard view.                      |
+----------+------------------------------+---------------------------------------+
|  5.3.1.2 |  View Profile Button         |  [ref All User 1.3.1.2]               |
|          |                              |  Opens the profile page showing name, |
|          |                              |  email, gender, phone number, date of |
|          |                              |  birth, and profile picture.          |
+----------+------------------------------+---------------------------------------+
|  5.3.1.3 |  Edit Profile Button         |  [ref All User 1.3.1.2.7]             |
|          |                              |  Opens the edit form pre-filled with  |
|          |                              |  existing values. On submission,      |
|          |                              |  updated info is saved and the user   |
|          |                              |  returns to the view profile page.    |
+----------+------------------------------+---------------------------------------+
|  5.3.1.4 |  Change Profile Picture      |  [ref All User 1.3.1.2.8]             |
|          |  Button                      |  Opens an upload control. On          |
|          |                              |  submission, the new picture is saved |
|          |                              |  and the user returns to view profile.|
+----------+------------------------------+---------------------------------------+
|  5.3.1.5 |  Change Password Button      |  [ref All User 1.3.1.5]               |
|          |                              |  Opens a form to enter current        |
|          |                              |  password, new password, and confirm  |
|          |                              |  new password. On submission, the     |
|          |                              |  password is updated.                 |
+----------+------------------------------+---------------------------------------+
|  5.3.1.6 |  Combined Dashboard          |  Opens a single screen displaying the |
|          |  View Button                 |  weekly meal plan calendar and the    |
|          |                              |  auto-generated shopping list side by |
|          |                              |  side. The shopping list updates live |
|          |                              |  whenever any meal plan slot changes. |
+----------+------------------------------+---------------------------------------+
| 5.3.1.6.1|  Side-by-Side View           |  The weekly planner and shopping list |
|          |                              |  are displayed simultaneously on one  |
|          |                              |  screen without navigating between    |
|          |                              |  separate pages.                      |
+----------+------------------------------+---------------------------------------+
| 5.3.1.6.2|  Live Shopping List Update   |  The shopping list panel refreshes    |
|          |                              |  automatically whenever a recipe is   |
|          |                              |  added to, removed from, or changed   |
|          |                              |  in any meal slot.                    |
+----------+------------------------------+---------------------------------------+
|  5.3.1.7 |  Search by Ingredient        |  Accepts one or more ingredient       |
|          |  Button                      |  names. Returns all recipes whose     |
|          |                              |  ingredient lists contain every       |
|          |                              |  specified ingredient. Found recipes  |
|          |                              |  can be added directly to the meal    |
|          |                              |  plan from the results list.          |
+----------+------------------------------+---------------------------------------+
| 5.3.1.7.1|  Taking Ingredient Names     |  Accepts one or more ingredient       |
|          |                              |  names as text input from the user.   |
+----------+------------------------------+---------------------------------------+
| 5.3.1.7.2|  Submitting the Form         |  Triggers the ingredient-based        |
|          |                              |  search query against the recipe      |
|          |                              |  collection.                          |
+----------+------------------------------+---------------------------------------+
| 5.3.1.7.3|  Show Matching Recipes       |  Returns and displays all recipes     |
|          |                              |  whose ingredient lists contain every |
|          |                              |  specified ingredient entered by      |
|          |                              |  the user.                            |
+----------+------------------------------+---------------------------------------+
| 5.3.1.7.4|  Add to Meal Plan from       |  The user can assign a found recipe   |
|          |  Results                     |  directly to a chosen calendar slot   |
|          |                              |  from the search results list without |
|          |                              |  navigating away.                     |
+----------+------------------------------+---------------------------------------+
|  5.3.1.8 |  Weekly Meal Planner Button  |  [ref Family User 2.3.1.8]            |
|          |                              |  Opens the 7-day planner grid with    |
|          |                              |  breakfast, lunch, and dinner slots   |
|          |                              |  per day. Save and load template      |
|          |                              |  shortcuts are prominently accessible.|
+----------+------------------------------+---------------------------------------+
| 5.3.1.8.1|  Save Plan as Template       |  [ref Family User 2.3.1.8.4]          |
|          |                              |  Accepts a template name and saves    |
|          |                              |  the current week's meal assignments  |
|          |                              |  as a named reusable template.        |
+----------+------------------------------+---------------------------------------+
| 5.3.1.8.2|  Load Template               |  [ref Family User 2.3.1.8.5]          |
|          |  (One-Click Apply)           |  Applies the selected saved template  |
|          |                              |  to the current week's calendar in    |
|          |                              |  one action, replacing all existing   |
|          |                              |  assignments.                         |
+----------+------------------------------+---------------------------------------+
|  5.3.1.9 |  Shopping List Button        |  [ref Family User 2.3.1.9]            |
|          |                              |  Opens the auto-generated shopping    |
|          |                              |  list from the active meal plan with  |
|          |                              |  ingredient merging, category         |
|          |                              |  grouping, and checkbox check-off.    |
|          |                              |  Serving size adjustment is available |
|          |                              |  directly from this view.             |
+----------+------------------------------+---------------------------------------+
| 5.3.1.9.1|  Serving Size from           |  The user can adjust the serving size |
|          |  Shopping List View          |  of any planned recipe directly from  |
|          |                              |  the shopping list view. All          |
|          |                              |  ingredient quantities update         |
|          |                              |  automatically upon change.           |
+----------+------------------------------+---------------------------------------+
| 5.3.1.10 |  Logout Button               |  [ref All User 1.3.1.6]               |
|          |                              |  Ends the user session and redirects  |
|          |                              |  to the login page.                   |
+----------+------------------------------+---------------------------------------+
|  5.3.2   |  Header                      |  [ref All User 1.3.2]                 |
|          |                              |  Displays platform logo on top left,  |
|          |                              |  logged-in username on top right,     |
|          |                              |  and logout button on top right.      |
+----------+------------------------------+---------------------------------------+
|  5.3.3   |  Footer                      |  [ref All User 1.3.3]                 |
|          |                              |  Displays links to Privacy Policy,    |
|          |                              |  Disclaimer, and About Us pages.      |
+----------+------------------------------+---------------------------------------+

================================================================================
                   RECIPE BOOK AND MEAL PLANNER SYSTEM

                     User: Home Cooking Enthusiast
              
                        Functional Requirements
 

+----------+------------------------------+---------------------------------------+
|  No.     |  Feature / Requirement       |  Description                          |
+----------+------------------------------+---------------------------------------+
|  3.0     |  User Home Page              |  All features are accessible from the |
|          |                              |  home page upon login.                |
+----------+------------------------------+---------------------------------------+
|  3.1     |  Registration                |  New users register by providing full |
|          |  [ref All User 1.1]          |  name, email, username, password,     |
|          |                              |  confirm password, gender, phone      |
|          |                              |  number, and date of birth. The form  |
|          |                              |  can be submitted or reset.           |
+----------+------------------------------+---------------------------------------+
|  3.2     |  Login                       |  Registered users log in using        |
|          |  [ref All User 1.2]          |  username and password. A forgot      |
|          |                              |  password option is provided.         |
+----------+------------------------------+---------------------------------------+
|  3.3     |  Dashboard                   |  The main dashboard provides access   |
|          |                              |  to all features through a side menu, |
|          |                              |  header, and footer.                  |
+----------+------------------------------+---------------------------------------+
|  3.3.1   |  Side Menu                   |  Contains all navigation buttons for  |
|          |                              |  Home Cooking Enthusiast features.    |
+----------+------------------------------+---------------------------------------+
|  3.3.1.1 |  Dashboard Button            |  Navigates the user back to the main  |
|          |  [ref 3.3]                   |  dashboard view.                      |
+----------+------------------------------+---------------------------------------+
|  3.3.1.2 |  View Profile Button         |  [ref All User 1.3.1.2]               |
|          |                              |  Opens the profile page showing name, |
|          |                              |  email, gender, phone number, date of |
|          |                              |  birth, and profile picture.          |
+----------+------------------------------+---------------------------------------+
|  3.3.1.3 |  Edit Profile Button         |  [ref All User 1.3.1.2.7]             |
|          |                              |  Opens the edit form pre-filled with  |
|          |                              |  existing values. On submission,      |
|          |                              |  updated info is saved and the user   |
|          |                              |  returns to the view profile page.    |
+----------+------------------------------+---------------------------------------+
|  3.3.1.4 |  Change Profile Picture      |  [ref All User 1.3.1.2.8]             |
|          |  Button                      |  Opens an upload control. On          |
|          |                              |  submission, the new picture is saved |
|          |                              |  and the user returns to view profile.|
+----------+------------------------------+---------------------------------------+
|  3.3.1.5 |  Change Password Button      |  [ref All User 1.3.1.5]               |
|          |                              |  Opens a form to enter current        |
|          |                              |  password, new password, and confirm  |
|          |                              |  new password. On submission, the     |
|          |                              |  password is updated.                 |
+----------+------------------------------+---------------------------------------+
|  3.3.1.6 |  My Recipe Box Button        |  [ref Family User 2.3.1.6]            |
|          |                              |  Opens the recipe collection as a     |
|          |                              |  card grid. Supports real-time search |
|          |                              |  by title, ingredient, or tag. Each   |
|          |                              |  card links to the recipe detail view.|
+----------+------------------------------+---------------------------------------+
| 3.3.1.6.1|  Show All Saved Recipes      |  Displays all the user's saved recipes|
|          |                              |  in a card grid layout.               |
+----------+------------------------------+---------------------------------------+
| 3.3.1.6.2|  Search and Filter Recipes   |  Filters the card grid in real time   |
|          |                              |  as the user types a title,           |
|          |                              |  ingredient name, cuisine, category,  |
|          |                              |  or keyword.                          |
+----------+------------------------------+---------------------------------------+
| 3.3.1.6.3|  View Recipe Detail          |  Opens a detail page showing the      |
|          |                              |  recipe title, full ingredient list,  |
|          |                              |  step-by-step instructions, tags,     |
|          |                              |  and notes.                           |
+----------+------------------------------+---------------------------------------+
| 3.3.1.6.4|  Add New Recipe Button       |  Opens the Add / Edit Recipe form     |
|          |  [ref 3.3.1.7]               |  to create a new recipe.              |
+----------+------------------------------+---------------------------------------+
| 3.3.1.6.5|  Edit Recipe Button          |  Opens the Add / Edit Recipe form     |
|          |  [ref 3.3.1.7]               |  pre-filled with the selected         |
|          |                              |  recipe's existing data.              |
+----------+------------------------------+---------------------------------------+
| 3.3.1.6.6|  Delete Recipe Button        |  Shows a confirmation prompt. On      |
|          |                              |  confirmation, the recipe is          |
|          |                              |  permanently removed from the         |
|          |                              |  collection.                          |
+----------+------------------------------+---------------------------------------+
|  3.3.1.7 |  Add / Edit Recipe Button    |  Form to create or update a recipe.   |
|          |                              |  Fields: title, dynamic ingredient    |
|          |                              |  rows (name, quantity, unit), dynamic |
|          |                              |  step rows, photo upload, tags,       |
|          |                              |  serving size, and notes. On          |
|          |                              |  submission, the recipe is saved to   |
|          |                              |  the user's collection.               |
+----------+------------------------------+---------------------------------------+
| 3.3.1.7.1|  Taking Recipe Title         |  Accepts the recipe name as a         |
|          |                              |  required text field.                 |
+----------+------------------------------+---------------------------------------+
| 3.3.1.7.2|  Taking Ingredients          |  Accepts a dynamic list of rows,      |
|          |                              |  each with ingredient name, quantity, |
|          |                              |  and unit of measurement.             |
+----------+------------------------------+---------------------------------------+
| 3.3.1.7.3|  Taking Cooking Steps        |  Accepts a dynamic list of            |
|          |                              |  step-by-step instruction rows.       |
+----------+------------------------------+---------------------------------------+
| 3.3.1.7.4|  Taking Recipe Photo         |  Accepts an image upload for the      |
|          |                              |  recipe photo.                        |
+----------+------------------------------+---------------------------------------+
| 3.3.1.7.5|  Taking Tags                 |  Accepts tags for cuisine type        |
|          |                              |  (e.g., Italian, Bengali), meal       |
|          |                              |  category (breakfast, lunch, dinner,  |
|          |                              |  dessert), and dietary restriction.   |
+----------+------------------------------+---------------------------------------+
| 3.3.1.7.6|  Taking Serving Size         |  Accepts a numeric value indicating   |
|          |                              |  how many people the recipe serves.   |
+----------+------------------------------+---------------------------------------+
| 3.3.1.7.7|  Taking Notes                |  Accepts optional free-text cooking   |
|          |                              |  tips or notes for the recipe.        |
+----------+------------------------------+---------------------------------------+
| 3.3.1.7.8|  Submitting the Form         |  Validates all required fields and    |
|          |                              |  saves the recipe to the user's       |
|          |                              |  collection.                          |
+----------+------------------------------+---------------------------------------+
|  3.3.1.8 |  Adjust Serving Size Button  |  Accepts a new numeric serving size.  |
|          |                              |  All ingredient quantities            |
|          |                              |  recalculate proportionally and       |
|          |                              |  display updated values immediately.  |
+----------+------------------------------+---------------------------------------+
| 3.3.1.8.1|  Taking New Serving Size     |  Accepts a positive integer or        |
|          |                              |  decimal as the new serving count.    |
+----------+------------------------------+---------------------------------------+
| 3.3.1.8.2|  Proportional Recalculation  |  All ingredient quantities are        |
|          |                              |  recalculated and updated values are  |
|          |                              |  displayed immediately in the recipe  |
|          |                              |  view.                                |
+----------+------------------------------+---------------------------------------+
|  3.3.1.9 |  Favorites Button            |  Opens a card grid showing all        |
|          |                              |  recipes the user has marked as       |
|          |                              |  favorite. Recipes can be removed     |
|          |                              |  from favorites here.                 |
+----------+------------------------------+---------------------------------------+
| 3.3.1.9.1|  Show Favorites Grid         |  Displays only recipes marked as      |
|          |                              |  favorite by the user in a card grid. |
+----------+------------------------------+---------------------------------------+
| 3.3.1.9.2|  Remove from Favorites       |  Unfavorites the selected recipe and  |
|          |                              |  removes it from the favorites grid.  |
+----------+------------------------------+---------------------------------------+
| 3.3.1.10 |  Rate Recipe Button          |  Opens a star rating control (1 to 5  |
|          |                              |  stars). Submitting the selected      |
|          |                              |  rating saves it to the recipe        |
|          |                              |  record.                              |
+----------+------------------------------+---------------------------------------+
|3.3.1.10.1|  Star Rating Control         |  Displays a 1-to-5 star selector for  |
|          |                              |  the selected recipe.                 |
+----------+------------------------------+---------------------------------------+
|3.3.1.10.2|  Submit Rating               |  Saves the selected star rating value |
|          |                              |  to the recipe record permanently.    |
+----------+------------------------------+---------------------------------------+
| 3.3.1.11 |  Share Recipe Button         |  Accepts a recipient username. On     |
|          |                              |  submission, a share request is sent. |
|          |                              |  The shared recipe appears in the     |
|          |                              |  recipient's collection upon          |
|          |                              |  acceptance.                          |
+----------+------------------------------+---------------------------------------+
|3.3.1.11.1|  Taking Recipient Username   |  Accepts the username of the          |
|          |                              |  registered user to share the recipe  |
|          |                              |  with.                                |
+----------+------------------------------+---------------------------------------+
|3.3.1.11.2|  Submitting the Share        |  Sends the share request to the       |
|          |  Request                     |  specified recipient.                 |
+----------+------------------------------+---------------------------------------+
|3.3.1.11.3|  Recipient Receives Recipe   |  The shared recipe appears in the     |
|          |                              |  recipient's collection once they     |
|          |                              |  accept the share request.            |
+----------+------------------------------+---------------------------------------+
| 3.3.1.12 |  Recommendations Button      |  Displays recipe recommendations      |
|          |                              |  based on the user's saved tags and   |
|          |                              |  past meal plan history. Each         |
|          |                              |  recommendation links to a full       |
|          |                              |  recipe detail view.                  |
+----------+------------------------------+---------------------------------------+
|3.3.1.12.1|  Show Recommendations        |  Displays a list of recommended       |
|          |                              |  recipes matched to the user's saved  |
|          |                              |  tags and meal plan history.          |
+----------+------------------------------+---------------------------------------+
|3.3.1.12.2|  View Recipe Detail          |  Opens the full recipe detail page    |
|          |  [ref Family User 2.3.1.6.3] |  for the selected recommended recipe. |
+----------+------------------------------+---------------------------------------+
| 3.3.1.13 |  Weekly Meal Planner Button  |  [ref Family User 2.3.1.8]            |
|          |                              |  Opens the 7-day planner grid with    |
|          |                              |  breakfast, lunch, and dinner slots   |
|          |                              |  per day. Includes save and load      |
|          |                              |  template features.                   |
+----------+------------------------------+---------------------------------------+
| 3.3.1.14 |  Shopping List Button        |  [ref Family User 2.3.1.9]            |
|          |                              |  Opens the auto-generated shopping    |
|          |                              |  list from the active meal plan with  |
|          |                              |  ingredient merging, category         |
|          |                              |  grouping, and checkbox check-off.    |
+----------+------------------------------+---------------------------------------+
| 3.3.1.15 |  Logout Button               |  [ref All User 1.3.1.6]               |
|          |                              |  Ends the user session and redirects  |
|          |                              |  to the login page.                   |
+----------+------------------------------+---------------------------------------+
|  3.3.2   |  Header                      |  [ref All User 1.3.2]                 |
|          |                              |  Displays platform logo on top left,  |
|          |                              |  logged-in username on top right,     |
|          |                              |  and logout button on top right.      |
+----------+------------------------------+---------------------------------------+
|  3.3.3   |  Footer                      |  [ref All User 1.3.3]                 |
|          |                              |  Displays links to Privacy Policy,    |
|          |                              |  Disclaimer, and About Us pages.      |
+----------+------------------------------+---------------------------------------+

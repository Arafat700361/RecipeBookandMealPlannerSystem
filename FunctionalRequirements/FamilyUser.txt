================================================================================
                  RECIPE BOOK AND MEAL PLANNER SYSTEM
                   
                             User: Family User

          
                           Functional Requirements

+----------+-----------------------------+----------------------------------------+
|  No.     |  Feature / Requirement      |  Description                           |
+----------+-----------------------------+----------------------------------------+
|  2.0     |  User Home Page             |  All features are accessible from the  |
|          |                             |  home page upon login.                 |
+----------+-----------------------------+----------------------------------------+
|  2.1     |  Registration               |  New users register by providing full  |
|          |  [ref All User 1.1]         |  name, email, username, password,      |
|          |                             |  confirm password, gender, phone       |
|          |                             |  number, and date of birth. The form   |
|          |                             |  can be submitted or reset.            |
+----------+-----------------------------+----------------------------------------+
|  2.2     |  Login                      |  Registered users log in using         |
|          |  [ref All User 1.2]         |  username and password with a forgot   |
|          |                             |  password option available.            |
+----------+-----------------------------+----------------------------------------+
|  2.3     |  Dashboard                  |  The main dashboard provides access    |
|          |                             |  to all features through a side menu,  |
|          |                             |  header, and footer.                   |
+----------+-----------------------------+----------------------------------------+
|  2.3.1   |  Side Menu                  |  Contains all navigation buttons for   |
|          |                             |  Family User features.                 |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.1 |  Dashboard Button           |  Navigates the user back to the main   |
|          |  [ref 2.3]                  |  dashboard view.                       |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.2 |  View Profile Button        |  [ref All User 1.3.1.2]                |
|          |                             |  Opens the profile page showing name,  |
|          |                             |  email, gender, phone number, date of  |
|          |                             |  birth, and profile picture.           |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.3 |  Edit Profile Button        |  [ref All User 1.3.1.2.7]              |
|          |                             |  Opens the edit form pre-filled with   |
|          |                             |  existing values. On submission,       |
|          |                             |  updated info is saved.                |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.4 |  Change Profile Picture     |  [ref All User 1.3.1.2.8]              |
|          |  Button                     |  Opens an upload control. On           |
|          |                             |  submission, the new picture is saved. |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.5 |  Change Password Button     |  [ref All User 1.3.1.5]                |
|          |                             |  Opens a form to enter current         |
|          |                             |  password, new password, and confirm   |
|          |                             |  new password. On submission, the      |
|          |                             |  password is updated.                  |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.6 |  My Recipe Box Button       |  Opens the recipe collection shown as  |
|          |                             |  a card grid. Supports real-time       |
|          |                             |  search by title, ingredient, or tag.  |
|          |                             |  Each card links to recipe detail.     |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.6.1|  Show All Saved Recipes     |  Displays all the user's saved recipes |
|          |                             |  in a card grid layout.                |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.6.2|  Search and Filter Recipes  |  Filters the card grid in real time as |
|          |                             |  the user types a title, ingredient    |
|          |                             |  name, or tag.                         |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.6.3|  View Recipe Detail         |  Opens a detail page showing title,    |
|          |                             |  full ingredient list, step-by-step    |
|          |                             |  instructions, tags, and notes.        |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.6.4|  Add New Recipe Button      |  Opens the Add / Edit Recipe form      |
|          |  [ref 2.3.1.7]              |  to create a new recipe.               |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.6.5|  Edit Recipe Button         |  Opens the Add / Edit Recipe form      |
|          |  [ref 2.3.1.7]              |  pre-filled with the selected          |
|          |                             |  recipe's existing data.               |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.6.6|  Delete Recipe Button       |  Shows a confirmation prompt. On       |
|          |                             |  confirmation, the recipe is           |
|          |                             |  permanently removed from the          |
|          |                             |  collection.                           |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.7 |  Add / Edit Recipe          |  Form to create or update a recipe.    |
|          |                             |  Fields: title, dynamic ingredient     |
|          |                             |  rows (name, quantity, unit), dynamic  |
|          |                             |  step rows, photo upload, tags,        |
|          |                             |  serving size, and notes. On           |
|          |                             |  submission, the recipe is saved.      |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.7.1|  Taking Recipe Title        |  Accepts the recipe name as a          |
|          |                             |  required text field.                  |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.7.2|  Taking Ingredients         |  Accepts a dynamic list of rows,       |
|          |                             |  each with ingredient name, quantity,  |
|          |                             |  and unit of measurement.              |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.7.3|  Taking Cooking Steps       |  Accepts a dynamic list of             |
|          |                             |  step-by-step instruction rows.        |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.7.4|  Taking Recipe Photo        |  Accepts an image upload for the       |
|          |                             |  recipe photo.                         |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.7.5|  Taking Tags                |  Accepts tags for cuisine type, meal   |
|          |                             |  category, and dietary restriction.    |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.7.6|  Taking Serving Size        |  Accepts a numeric value indicating    |
|          |                             |  how many people the recipe serves.    |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.7.7|  Taking Notes               |  Accepts optional free-text cooking    |
|          |                             |  tips or notes for the recipe.         |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.7.8|  Submitting the Form        |  Validates all required fields and     |
|          |                             |  saves the recipe to the user's        |
|          |                             |  collection.                           |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.8 |  Weekly Meal Planner Button |  Opens the 7-day planner grid with     |
|          |                             |  breakfast, lunch, and dinner slots    |
|          |                             |  per day.                              |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.8.1|  Show 7-Day Calendar Grid   |  Displays seven day columns, each      |
|          |                             |  with three meal slots: breakfast,     |
|          |                             |  lunch, and dinner.                    |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.8.2|  Add Recipe to Slot         |  Opens a searchable recipe picker.     |
|          |                             |  The selected recipe is assigned to    |
|          |                             |  the chosen meal slot.                 |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.8.3|  Remove Recipe from Slot    |  Removes the recipe assignment from    |
|          |                             |  that slot only, leaving all other     |
|          |                             |  slots unchanged.                      |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.8.4|  Save Plan as Template      |  Accepts a template name and saves     |
|          |                             |  the current week's meal assignments   |
|          |                             |  as a named reusable template.         |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.8.5|  Load Template              |  Shows a list of saved templates.      |
|          |                             |  Applying one replaces the current     |
|          |                             |  week's assignments with the           |
|          |                             |  template's assignments.               |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.8.6|  Clear Week                 |  Shows a confirmation prompt. On       |
|          |                             |  confirmation, all recipe assignments  |
|          |                             |  for the current week are removed.     |
+----------+-----------------------------+----------------------------------------+
|  2.3.1.9 |  Shopping List Button       |  Opens the auto-generated shopping     |
|          |                             |  list for the active week's meal plan. |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.9.1|  Show Auto-Generated List   |  Displays all ingredients from all     |
|          |                             |  planned recipes, merged and totalled  |
|          |                             |  automatically with no manual input.   |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.9.2|  Ingredient Merging         |  Duplicate ingredients across          |
|          |                             |  different recipes are combined into   |
|          |                             |  a single entry with the correctly     |
|          |                             |  summed quantity and unit.             |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.9.3|  Category Grouping          |  The list is displayed grouped by:     |
|          |                             |  Produce, Protein, Dairy & Eggs,       |
|          |                             |  Pantry, Bakery, Spices &              |
|          |                             |  Condiments, and Other.                |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.9.4|  Checkbox per Item          |  Each item has a checkbox. Tapping it  |
|          |                             |  marks the item as collected and       |
|          |                             |  applies a visual distinction such     |
|          |                             |  as strikethrough.                     |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.9.5|  Reset All Checks Button    |  Clears all checkboxes on the list     |
|          |                             |  in a single action, ready for the     |
|          |                             |  next shopping trip.                   |
+----------+-----------------------------+----------------------------------------+
| 2.3.1.9.6|  Live List Updates          |  The list updates automatically        |
|          |                             |  whenever any meal plan slot is        |
|          |                             |  added to, changed, or cleared.        |
+----------+-----------------------------+----------------------------------------+
|2.3.1.10  |  Logout Button              |  Ends the user session and redirects   |
|          |  [ref All User 1.3.1.6]     |  to the login page.                    |
+----------+-----------------------------+----------------------------------------+
|  2.3.2   |  Header                     |  [ref All User 1.3.2]                  |
|          |                             |  Displays platform logo on top left,   |
|          |                             |  logged-in username on top right,      |
|          |                             |  and logout button on top right.       |
+----------+-----------------------------+----------------------------------------+
|  2.3.3   |  Footer                     |  [ref All User 1.3.3]                  |
|          |                             |  Displays links to Privacy Policy,     |
|          |                             |  Disclaimer, and About Us pages.       |
+----------+-----------------------------+----------------------------------------+
